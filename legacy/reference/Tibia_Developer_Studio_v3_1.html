Jedno studio do rozwijania całej gry

Studio działa lokalnie. Wczytany plik gry jest uruchamiany w roboczym podglądzie, a edytor łączy się z jego prawdziwymi interfejsami TibiaAssetAPI, TibiaMapAPI i opcjonalnym TibiaContentAPI. Wczytuj wyłącznie pliki gry, którym ufasz. Oryginał nie jest nadpisywany. Dopiero przy zapisie powstaje nowy HTML z osadzonymi teksturami PNG i zmodyfikowanym światem.

Najpełniejszą obsługę zapewnia dołączony silnik v14.1 z transakcyjnym Project API; starsze wersje działają w trybie ograniczonym.

🗺 Wielopoziomowy edytor map

Edycja pięciu warstw 200×200, pędzel, linia, prostokąt, wiadro, pipeta, kolizje, siatka, spawny, NPC, wejścia i przejścia między piętrami. Pełne undo/redo.

🧩 Content Studio

Edycja definicji potworów, klas, aktywnych umiejętności i zadań. Nowe potwory otrzymują proceduralny wygląd zastępczy i własny identyfikator atlasu PNG.
