# Dla agentów

**To repozytorium nie jest zakwalifikowane przez właściciela i `main` nie jest jego najnowszym stanem.**
Ten plik istnieje po to, żeby ostrzeżenie dotarło do agenta, a nie tylko do człowieka czytającego
README na GitHubie: `AGENTS.md` wczytuje się samo przy starcie pracy w katalogu repozytorium,
README nie wczytuje się nigdy.

## Zanim cokolwiek tu zrobisz

1. **`main` opisuje 15 VI 2026** (M8 VS-3, „owner retest”). Wszystko nowsze nigdy tu nie trafiło.
2. **Nowsza praca leży w niescalonych PR-ach:** łańcuch B1–B5 i odrodzenie R0 z 22–23 X (PR #1–#8),
   dokument autorski A0/A1 i dwa eksperymenty edytora z 9–10 XI (PR #11–#13). Żaden nie jest
   zakwalifikowany przez właściciela.
3. **Ostatnia rzecz, do której wraca właściciel:**
   `experiments/coopege-one-world-authoring/continuity-2026-10-26/Coopege_Powrot_Do_Swiata_2026-10-26.html`
   na gałęzi `experiment/coopege-portable-return-2026-10-26` — otwierana lokalnie, bez żywego adresu.
   Dowody CI z 23–24 X: gałąź `dowody/ci-2026-10-23-24`.
4. **Nie promuj gałęzi badawczej tylko po to, żeby `main` wyglądał na aktualny.** Rzeczy nieodwracalne
   — kasowanie gałęzi, publikacja, dostępy — należą wyłącznie do właściciela.
5. **Nie kasuj gałęzi.** Dla większości tej pracy gałąź jest jedyną kopią.
